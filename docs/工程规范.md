### 3.2 前端 `.env.development`

```dotenv
VUE_APP_API_BASE_URL=http://127.0.0.1:8000/api/v1
```

> 只有 `VUE_APP_` 前缀会注入前端包；**前端环境变量里不得出现任何密钥**。

### 3.3 规则

1. `.env` 全部 gitignore，仓库只提交 `.env.example`。
2. `core/config.py` 是唯一读环境变量的地方，其余代码通过 `settings` 对象访问。
3. 缺失必填变量应在启动时立即报错退出，不要带病运行。

## 4. Git 工作流

### 4.1 分支

```text
main       ← 每个版本验收通过后合并，可运行状态
develop    ← 日常开发基线
feature/*  ← 单个功能，如 feature/v1.0-tasks-crud
fix/*      ← 缺陷修复
```

### 4.2 提交信息

```text
<type>(<scope>): <说明>
```

| type | 用途 | 示例 |
|---|---|---|
| feat | 新功能 | `feat(tasks): 增加按状态筛选与逾期标记` |
| fix | 修复 | `fix(expenses): 修正月度汇总跨时区偏差` |
| docs | 文档 | `docs(db): 补充 categories 的 seed 说明` |
| refactor | 重构 | `refactor(auth): 抽出 TokenVerifier 抽象` |
| test | 测试 | `test(isolation): 增加跨用户访问 404 用例` |
| chore | 杂务 | `chore(deps): 锁定 bcrypt 4.0.1` |

`scope` 取值：`tasks` / `expenses` / `auth` / `ai` / `rag` / `admin` / `analytics` / `db` / `web` / `deploy` / `docs`

### 4.3 版本标签

每个版本验收通过打 tag：`v1.0.0`、`v1.1.0`、`v1.2.0`、`v1.3.0`、`v1.4.0`、`v2.0.0`。

## 5. 代码规范

### 5.1 后端

| 项 | 规范 |
|---|---|
| 格式化 | `ruff format`（行宽 100） |
| 静态检查 | `ruff check`，规则集 `E,F,I,N,UP,B,SIM` |
| 类型标注 | 所有函数签名标注类型；`services/` 与 `repositories/` 必须完整 |
| 命名 | 模块 `snake_case.py`；类 `PascalCase`；常量 `UPPER_SNAKE` |
| 路由分层 | endpoint 只做参数绑定 + 调 service，业务逻辑不写在 endpoint |
| ORM 访问 | 只在 `repositories/` 中出现 `db.query/select`，拒绝在 endpoint 裸写 |
| 异常 | 业务错误抛 `AppError`，不抛裸 `HTTPException`（除认证依赖） |
| 日志 | 用 `logging.getLogger(__name__)`，禁止 `print` |
| 注释 | 解释「为什么」，不复述「是什么」；中文注释可 |

### 5.2 前端

| 项 | 规范 |
|---|---|
| 组件命名 | 文件名 `PascalCase.vue`，模板中使用 kebab-case |
| 组件风格 | 统一选项式 API（Vue 2 项目一致性好），不混用 Composition API |
| 状态管理 | 全局状态（用户、字典）进 Vuex；页面局部状态留在组件 |
| 请求 | 全部走 `api/request.js` 实例，禁止在组件里直接 `axios.get` |
| 样式 | SCSS + BEM 命名；全局变量在 `styles/variables.scss` |
| 时间 | 统一用 `utils/time.js` 包装 dayjs，禁止手写格式化 |
| 常量 | 枚举文案（状态、优先级）集中在 `utils/constants.js`，与后端枚举一致 |

## 6. 本地开发启动

### 6.1 后端

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
copy .env.example .env          # 然后填写 DATABASE_URL
alembic upgrade head            # 建表 + seed
uvicorn app.main:app --reload --port 8000
```

访问 `http://127.0.0.1:8000/docs` 验证。

### 6.2 前端

```bash
cd frontend
npm install --legacy-peer-deps
npm run serve                   # 默认 8080
```

### 6.3 端口约定

| 服务 | 端口 |
|---|---|
| backend | 8000 |
| frontend | 8080 |
| analytics-web | 8081 |
| admin-web | 8082 |
| MySQL | 3306 |
| Milvus | 19530 |
| Keycloak | 8083（避免与前端冲突） |
