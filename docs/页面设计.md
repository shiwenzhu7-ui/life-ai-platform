## 1. 生活管理端 `frontend`（V1.0 起）

### 1.1 路由表

| 路径 | 页面 | 版本 | 说明 |
|---|---|---|---|
| `/login` | 登录 | V1.2 | V1.0 无此页，直接进首页 |
| `/` | 首页仪表盘 | V1.0 | 默认重定向到此 |
| `/tasks` | 待办事项 | V1.0 | 列表 + 新建/编辑弹窗 |
| `/expenses` | 消费记账 | V1.0 | 列表 + 记账弹窗 + 月度汇总条 |
| `/budgets` | 预算管理 | V1.4 | 总预算 + 分类预算 + 执行进度 |
| `/shopping` | 购物清单 | V1.4 | 左清单 / 右明细（V1.1 仅 AI 写入，无页面） |
| `/life` | 生活记录 | V1.4 | 标签页：饮食/饮水/运动/睡眠/心情 |
| `/diary` | 生活日记 | V1.4 | 列表 + 编辑器 |

| `/knowledge` | 个人知识库 | V1.3 | 文档列表 + 上传 + 处理状态 |

### 1.2 布局结构

```text
┌─────────────────────────────────────────────┐
│ Header：Logo | 搜索 | 通知铃铛 | 用户下拉    │
├──────────┬──────────────────────────────────┤
│ Sidebar  │  页面内容区（router-view）        │
│ 8 个菜单 │  面包屑 + 操作按钮 + 主体         │
│          │                                  │
└──────────┴──────────────────────────────────┘
```

- 桌面：Sidebar 固定 220px，可折叠至 64px。
- 移动端（<768px）：Sidebar 变为抽屉，底部不放 Tab（菜单项过多）。

### 1.3 页面要点

**首页仪表盘（V1.0）**
- 待办卡片：未开始/进行中/已完成/逾期 四数字 + 今日到期列表。
- 消费卡片：本月支出、上月支出、今日支出、近 7 天迷你柱状图。
- 快捷入口：新建待办、记一笔。
- 数据来源：`GET /dashboard/overview`。

**待办页（V1.0）**
- 顶部筛选条：状态（多选标签）、分类、优先级、日期范围、关键词搜索。
- 列表：复选框切状态、标题、分类标签、优先级色点、截止时间（逾期标红）、行内编辑/删除。
- 新建/编辑：右侧抽屉，字段同接口校验。
- 空状态：插画 + 「还没有待办，新建一个」按钮。

**消费页（V1.0）**
- 顶部：月份切换器 + 本月支出/收入/结余三个数字。
- 中部：类别占比横向条（ECharts 于 V1.4 换成饼图）。
- 列表：日期、类别、账户、金额（支出红/收入绿）、备注。
- 记账弹窗：类型切换（支出/收入）、金额大字输入、分类九宫格、账户、时间、标签、备注。

**AI 助手页（V1.1）**
- 左侧：会话列表（新建、重命名、删除）。
- 右侧：消息流 + 输入框（Enter 发送、Shift+Enter 换行）。
- **确认卡片**：当 `pending_action` 存在时，在 AI 消息下方渲染结构化预览
  - 待办：标题、分类、优先级、时间
  - 消费：金额、分类、账户、时间
  - 底部「确认保存」/「取消」两按钮，确认时按钮进入 loading 并禁用，防重复提交。
- 引用展示（V1.3）：答案下方折叠「参考来源」，列出文档名 + 页码 + 片段。
- 生成中：三点打字动画 + 「AI 正在思考」文案（NFR：必须显示生成状态）。

**知识库页（V1.3）**
- 上部：拖拽上传区（限 pdf/docx/txt，20MB）。
- 列表：文件名、大小、状态徽标（待处理/解析中/向量化中/就绪/失败）、分块数、上传时间、删除。
- 处理中：行内进度条，轮询 `GET /documents/{id}/task`（2s，指数退避至 10s）。
- 失败：显示 `error_message` + 「重新处理」按钮。

## 2. 数据分析端 `analytics-web`（V1.4）

### 2.1 路由表

| 路径 | 页面 | 说明 |
|---|---|---|
| `/` | 分析总览 | 关键指标卡片 |
| `/expenses` | 消费分析 | 趋势、类别占比、账户分布 |
| `/budgets` | 预算执行 | 各月/各类别执行率 |
| `/tasks` | 待办分析 | 完成率、逾期率、分类分布 |
| `/life` | 生活趋势 | 运动频率、睡眠时长、心情曲线 |
| `/reports` | 周报与月报 | 列表 + 详情 + 生成 |

### 2.2 图表清单（ECharts）

| 图表 | 类型 | 数据接口 |
|---|---|---|
| 近 6 月收支趋势 | 折线 + 柱状组合 | `/analytics/expense-trend` |
| 类别占比 | 环形饼图 | `/analytics/category-share` |
| 预算执行 | 横向进度条 + 阈值色 | `/analytics/budget-execution` |
| 待办完成率 | 环形 + 折线 | `/analytics/task-completion` |
| 运动频率 | 日历热力图 | `/analytics/exercise-frequency` |
| 睡眠与心情 | 双 Y 轴折线 | `/analytics/sleep-mood` |

> 所有图表必须支持「无数据」占位，不得报错或显示空白坐标系。

## 3. 系统管理后台 `admin-web`（V1.2 起）

### 3.1 路由表

| 路径 | 页面 | 版本 |
|---|---|---|
| `/login` | 管理员登录 | V1.2 |
| `/` | 概览统计 | V1.4 |
| `/users` | 用户管理 | V1.2 |
| `/roles` | 角色说明（只读） | V1.2 |
| `/ai-configs` | AI 模型配置 | V1.4 |
| `/logs` | 操作日志 | V1.4 |
| `/stats` | 系统调用统计 | V1.4 |
| `/knowledge` | 公共知识管理 | V1.4 |

### 3.2 要点

- 所有页面路由守卫校验 `role === 'admin'`，非管理员跳 403 页。
- **不得出现**任何查看用户私人日记、私人文档、对话记录的入口。
- 用户管理：改状态（启用/禁用）、改角色、调额度；禁止把最后一个管理员降级。
- AI 配置：只展示环境变量名，不展示密钥值。

## 4. 通用交互规范

| 场景 | 规范 |
|---|---|
| 加载中 | 首屏骨架屏；列表局部 loading 遮罩；按钮内联 spinner 并禁用 |
| 空状态 | 每个列表必须有插画 + 一句引导 + 主操作按钮 |
| 错误 | 表单字段下方红字；请求失败用顶部 message 提示（含 `request_id` 便于排查） |
| 删除确认 | 一律二次确认弹窗，显示对象名称 |
| 表单校验 | 失焦即时校验 + 提交前整体校验；必填项标红星 |
| 时间显示 | 相对时间（「3 分钟前」「明天 15:00」）+ hover 显示完整时间 |
| 移动端 | 断点 768px / 1200px；表格在窄屏转卡片列表 |
| 无障碍 | 表单 `label` 关联、按钮有 `aria-label`、颜色不作为唯一信息载体（优先级同时带文字） |
